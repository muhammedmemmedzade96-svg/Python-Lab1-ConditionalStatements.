# Python Lab 1 - Conditional Statements & Decision-Making

This repository contains the first laboratory assignment for the **Introduction to Python Programming** course at **Qarabag University** (Faculty of Engineering, Computer Engineering & Data Analytics).

## Project Overview
The application is structured as a unified, personalized console system that includes input validation and exception handling for all tasks.

### Included Applications:
1. **Body Mass Index (BMI) Calculator:** Calculates user BMI using metric inputs and determines weight categories.
2. **Chinese Zodiac Calculator:** Determines the corresponding zodiac animal using modular arithmetic on the birth year.
3. **Birthday Guessing Game:** Guesses the exact day of the month using five distinct binary group sets based on game logic.

## 💻 Tech Stack
- **Language:** Python 3.x
- **Concepts Used:** Functions (`def`), Infinite Loops (`while True`), Conditional Statements (`if-elif-else`), and Exception Handling (`try-except`).
